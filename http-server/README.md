
# Goal

Build a simplistic, minimal http server to learn how does it work at the system level.
The use of AI to generate any source code is strictly forbidden. I want to lean it myself.

Acceptance criterias are not included. I don't care.

# Plan

1. Build a server that accepts TCP connection.
2. Static http response.
3. Build a simple HTTP endpoint that accepts only http 1.0 get requests.
4. Build a file-serving server that can serve text images and some pdf files.
5. Add concurrency to the server.
